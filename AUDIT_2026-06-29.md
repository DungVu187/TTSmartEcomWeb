## ĐIỂM MẠNH (GIỮ NGUYÊN + ĐIỂM MỚI)

- **Bcrypt** hash password (cost 10) qua pre-save hook — không lưu plaintext
- **HttpOnly cookie** cho JWT — ngăn XSS đánh cắp token
- **Rate limiting** áp dụng đúng cho `/register`, `/login`, `/change-password`
- **Generic error message** khi login thất bại — ngăn user enumeration
- **`authenticateAdmin` tra DB** — phát hiện user đã bị xóa
- **Autologin nâng cấp lên secure token** — `crypto.randomBytes(32)`, invalidated khi đổi mật khẩu, admin có thể rotate
- **Dual-mode legacy fallback** — AES decrypt → tự động upgrade lên secure token khi user cũ đăng nhập lần đầu
- **Gemini AI scan invoice** với fallback 3 model + timeout 25s
- **Test coverage autologin** — 4 test case mới bao phủ register, legacy upgrade, invalidation, rotate
- **Cấu trúc route tách component** rõ ràng theo nghiệp vụ

**Khó bảo trì:** Duplicate code (file + logic), dead code chưa dọn, magic strings, config phân tán. Bất kỳ refactor nào đều có rủi ro miss một trong các bản copy.
