04 · Backend compatibility

Thiết kế này dùng dữ liệu backend đang có

Không cần schema mới cho phase đầu. Những phần chưa có backend được loại khỏi mockup: wishlist, compare sâu, shipping ETA, recommendation thật.

Product listing

Dùng GET /products, /chips/brands, /chips/types, /chips/section. UI map vào query hiện có: search, brand, type, section, value, code, sort, page.

Product card

Field dùng trực tiếp: name, code, brand, type, variant[0].imgUrl, variant[0].price, variant[0].quantityForSale.

Product detail

Dùng GET /products/:id. Variant selector map vào variantIndex, các tab lấy từ description, features, specifications, infoDoc.

Cart / order

Add cart dùng POST /carts/addToCart với productId và variantIndex. Update quantity dùng /carts/updateCartItem. Checkout dùng /orders/create-order.

Voice search

Search bar có nút mic map vào /products/voice-query và /products/voice-query-text. Kết quả trả về keyword, brand, type, code.

Không làm ở phase này

Không triển khai voice add/update/delete thật, wishlist, shipping ETA, recommendation thật hoặc compare thông số dạng structured vì backend chưa có đủ contract.
